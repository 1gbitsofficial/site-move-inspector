## Short description

Run a private, read-only Joomla migration preflight, compare destination hosting requirements, and export privacy-safe JSON or TXT reports.

## Full description

Site Move Inspector helps Joomla administrators identify hosting and migration risks before moving a site.

The component checks Joomla, PHP, database, web-server, extension, template, disk, and filesystem metadata. Its bounded and resumable scan stays inside the Joomla site root, does not read file contents, and reports only privacy-safe aggregates. Administrators can optionally enter a destination PHP, database, and disk profile to highlight compatibility or capacity gaps.

Reports are generated locally as JSON or TXT. Site Move Inspector does not create backups, transfer data, change Joomla configuration, inspect content or user records, or send telemetry to 1Gbits.

### Highlights

- Read-only migration and hosting preflight.
- Joomla 5.4 and Joomla 6.1 support.
- MySQL, MariaDB, and PostgreSQL support for temporary scan jobs.
- Bounded, resumable filesystem metadata scan with path and symlink protections.
- Optional destination-hosting comparison.
- Privacy-safe JSON and TXT exports.
- English and Persian administrator interface.
- Joomla Update System integration.

## Privacy statement

No site data is transmitted. Reports are generated locally and are not retained as report files. Only Joomla update checks access the public GitHub update feed.
